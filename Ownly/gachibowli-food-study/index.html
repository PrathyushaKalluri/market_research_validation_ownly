How a real visitor gets an arm

Each new browser gets a coin flip (crypto.getRandomValues), stored in that browser. The same person sees the same arm on every reload and every later visit. It is not alternating (A, B, A, B) and not in blocks (first 10% A): each visitor is an independent 50/50 draw, so the split is close to even but never exact.

What this page records
  • Anonymous interaction events: page opened, buttons tapped, and how long before a tap.
  • A random ID stored in your browser so repeat visits aren't double-counted. No ad-network cookies, no fingerprinting.
  • The campaign tag in the link you opened and the referring website's domain.
  • Only if you tap one: your answer to the single question after the button.
  • Never recorded: your name, phone number, email, exact location or IP address.
