# Poll Plan (v2, 2026-09-16)

| | |
|---|---|
| **How many polls** | **One** (Poll A, Ownly awareness). Down from three — see `exact_poll_copy.md` §1 |
| **Purpose** | A large-n, unscreened cross-check on the single KPI where the survey's self-selected sample is most biased upward |
| **Audience** | Large, loose WhatsApp/Telegram groups **already written off for the survey** |
| **Not the audience** | Any group that will receive, or has received, the survey link |
| **The rule** | If you'd ever want to say "…among students" or "…among members", it belongs in the survey, not a poll. Poll answers join to nothing |
| **The hidden cost** | D8 makes poll groups and survey groups disjoint, so **every poll group is a lost survey group**. With an 80-response target, polls are expensive |
| **Instrument** | `exact_poll_copy.md` §2, verbatim |
| **Sample goal** | 80+ votes |
| **Timing** | 12:30–13:30 or 20:00–22:00 |
| **Log** | `poll_tracker.csv` at post time; screenshot at close |
| **Analysis** | Raw counts and % of votes cast. No CIs, no significance tests — no screener, no denominator we control |
| **Reported as** | Side by side with the survey's awareness figure, never merged. The gap between them is a read on our sampling bias |
| **Kills the poll** | Admin objects → delete and note it. Under 15 votes → report the count and draw nothing from it |
