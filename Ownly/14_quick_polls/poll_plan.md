# Poll Plan

| | |
|---|---|
| **Purpose** | One blunt cross-check per construct, on an n the survey can't reach, at zero respondent cost |
| **Audience** | Large, loose WhatsApp/Telegram groups and Instagram stories where a 7-minute ask would not convert |
| **Not the audience** | Any group receiving the survey link — see the contamination rule |
| **Instrument** | `exact_poll_copy.md`, verbatim |
| **Sample goal** | Poll 1: 60+ · Poll 2: 60+ · Poll 3: 50+ |
| **Timing** | 12:30–13:30 or 20:00–22:00 |
| **Log** | `poll_tracker.csv`, filled at post time; screenshot at close |
| **Analysis** | Raw counts and % of votes cast. No CIs, no significance tests — there is no screener and no denominator we control |
| **Reported as** | A directional cross-check, in the appendix or as a callout beside the matching survey chart. **Never pooled into any survey n.** |
| **Kills the poll** | If a group admin objects, delete the poll and note it. If a poll gets fewer than 15 votes, report the count and draw nothing from it |
