# Interview Note-Taking Template

**Copy this file per interview** → `HYD-##_notes.md` (or `BLR-##_notes.md`). Fill during and immediately after the session.
**Rule:** keep the columns separate. **Verbatim** = the participant's exact words (use quotation marks, and write "≈" if paraphrased). **Observation** = what happened / what was seen. **Interpretation** = *your* reading, always labelled. Never move an interpretation into the verbatim column.
